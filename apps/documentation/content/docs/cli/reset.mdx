---
title: reset
description: Fix drifted config, or give a sandbox worktree a fresh start.
---

Need to bring your machine back in line? `reset` has you covered. Defined in `apps/machine/src/cli.ts:56`, handled by `cmdReset` in `apps/machine/src/index.ts:87`. It has two modes — pick the one you need.

```text
uma-machine reset [--only <k1,k2>] [--dry-run] [--prune]
uma-machine reset --fresh-start --sandbox <id> [--commit <sha>] [--repo <url>] [--branch <b>] [--task <id>] [--dry-run]
```

## Mode 1 — fix config (default)

Use this when `check` showed drift.

| Flag | What it does |
| --- | --- |
| `--only <k1,k2>` | Only fix these config keys. |
| `--dry-run` | Show what would happen, without changing anything. |
| `--prune` | Also remove unmanaged entries. Parsed by `parsePruneFlag` (default `false`). |
| `--json` | Get JSON receipts instead of `key: ok / FAILED — detail` lines. |

We run `resetAll({ dryRun, only, prune })`. You'll get exit `0` when every receipt is `ok`, else `2`.

```bash
uma-machine reset --dry-run
uma-machine reset --only agents,skills --prune
```

## Mode 2 — fresh-start a worktree (`--fresh-start`)

Use this when a sandbox worktree feels messy and you want a clean slate. This is the **only** reset path that touches a worktree; `sync` and config reset never do. Implemented in `src/git-binding.ts` (`freshStart` runs `git clean -fdx + git reset --hard`).

| Flag | What it does |
| --- | --- |
| `--fresh-start` | Switches to worktree mode. |
| `--sandbox <id>` | **Required** (or pass it as a positional arg). Missing it gives an error + exit `1`. |
| `--commit / --repo / --branch / --task` | Which ref to reset the worktree to. `--task` defaults to `"task"`. |
| `--dry-run` | Prints `would fresh-start <id> (git clean -fdx + reset --hard)` and changes nothing. |

```bash
uma-machine reset --fresh-start --sandbox task-abc123
uma-machine reset --fresh-start --sandbox task-abc123 --branch task/abc123 --dry-run
```

Exit `0` on `fresh-start <id>: clean`, `1` if it failed (`fresh-start <id> failed: ...`).
