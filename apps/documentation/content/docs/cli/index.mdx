The `uma-machine` binary is defined in `apps/machine/src/cli.ts` (`buildCli`, `parseCli`, `helpText`) and dispatched in `apps/machine/src/index.ts` (`main`). Parser is `cac("uma-machine")` with pure `parse()` — global `-h/--help` and `-v/--version` print help/version instead of running a command.

Interactive diagram: [/visualize/cli](/visualize/cli).

## Command index

| Command | Purpose | Handler |
| --- | --- | --- |
| `enroll` | Device-flow enrollment, writes identity + limits + SQLite | `enroll()` in `src/enroll.ts:107` |
| `daemon` | Run the device daemon (WS + heartbeat tick) | `runDaemon()` in `src/daemon.ts:144` |
| `check` | Check config drift against desired state | `cmdCheck` in `src/index.ts:66` |
| `reset` | Reset drifted config, or `--fresh-start` a worktree | `cmdReset` in `src/index.ts:87` |
| `sync` | Reset + persist per-key receipts locally | `cmdSync` → `performSync` in `src/sync.ts:17` |
| `history` | Show persisted heartbeat history | `cmdHistory` → `readHistory` in `src/heartbeat.ts:206` |
| `sandbox` | `sandbox list` / `sandbox prune` | `cmdSandbox` in `src/index.ts:184` |
| `run` | Execute one task once (manual `assign`) | `cmdRun` → `executeTask` in `src/execution.ts:309` |
| `version` / `help` | Version string / help text | `main()` in `src/index.ts:267` |

Full usage template (`helpText()`, `src/cli.ts:186`):

```text
uma-machine enroll --server <url> [--name <machine>] [--systemd] [--client-id <id>]
uma-machine daemon [--interval <seconds>]
uma-machine check [--only <k1,k2>] [--json]
uma-machine reset [--only <k1,k2>] [--dry-run] [--prune]
uma-machine reset --fresh-start --sandbox <id> [--commit <sha>] [--repo <url>] [--branch <b>] [--task <id>] [--dry-run]
uma-machine sync [--dry-run] [--json] [--only <k1,k2>]
uma-machine history [--range 24h|30d] [--json]
uma-machine sandbox list [--json]
uma-machine sandbox prune [--dry-run]
uma-machine run --task <id> [--prompt <text>] [--project <id>] [--repo <url>] [--commit <sha>] [--branch <b>] [--agent <bin>]
uma-machine version
```

## Global flags

| Flag | Effect |
| --- | --- |
| `-h, --help` / `help [command]` | Global help, or per-command cac help when a subcommand is given (`src/index.ts:274`) |
| `-v, --version` / `version` | Prints `uma-machine ${CLI_VERSION} (protocol v1)` (`src/version.ts:1`, `CLI_VERSION = "0.1.0"`) |

Numeric-looking flag values are normalized back to strings by `parseCli` (`src/cli.ts:146`); repeated `--only a --only b` joins to `"a,b"`.

## Config keys (`--only`)

Dependency order in `src/config/mod.ts:22` (`ORDERED_KEYS`):

`programs, git-login, adityab-agent, agents, files, providers, mcp, skills, systemd`

Alias: `sync` resolves to `skills` (`resolveKeys`, `src/config/mod.ts:34`). Unknown keys are rejected by `parseOnlyFlag` (`src/env.ts:101`).

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | ok / clean |
| `2` | drifted (`check`) or partial (`reset`, `sync`) |
| `1` | error (unknown command, missing required flag, `run` non-completed, fresh-start failure) |
| `3` | `UPGRADE_REQUIRED` — daemon only, version shortfall (`src/daemon.ts:56`) |

Tables respect `NO_COLOR`/non-TTY: `humanTable()` in `src/index.ts:25` strips `cli-table3` styling and `picocolors` disables color automatically. Errors are secret-redacted and truncated to 300 chars (`safeError`, `src/index.ts:47`).

| `UMA_HEARTBEAT_INTERVAL_S` | `30` (min 5) | daemon tick default |

| `UMA_SANDBOX_TTL_S` | `3600` (min 60) | daemon TTL reap |
| `UMA_AGENT_BIN` | auto-detected agent | `run --agent` default |
| `UMA_EXEC_PATH` | binary path | systemd `ExecStart` |
| `GH_TOKEN` / `GITHUB_TOKEN` | — | redactor secret + git auth |
| `MSB_MOCK` / `UMA_MSB_MOCK=1` | unset | force mock sandbox driver in tests |
