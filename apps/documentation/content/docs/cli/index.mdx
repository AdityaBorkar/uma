Welcome to `uma-machine`! The binary is defined in `apps/machine/src/cli.ts` (`buildCli`, `parseCli`, `helpText`) and run from `apps/machine/src/index.ts` (`main`). It uses `cac("uma-machine")` with a pure `parse()` — global `-h/--help` and `-v/--version` just print help or the version.

Prefer a diagram? See [/visualize/cli](/visualize/cli).

## Which command do I need?

| Command | Use it when you want to… | Handled by |
| --- | --- | --- |
| `enroll` | Connect this machine to a server for the first time | `enroll()` in `src/enroll.ts:107` |
| `daemon` | Keep the machine online, heartbeat, and run tasks | `runDaemon()` in `src/daemon.ts:144` |
| `check` | See what drifted, without changing anything | `cmdCheck` in `src/index.ts:66` |
| `reset` | Fix drifted config, or clean a worktree with `--fresh-start` | `cmdReset` in `src/index.ts:87` |
| `sync` | Converge config and save receipts locally | `cmdSync` → `performSync` in `src/sync.ts:17` |
| `history` | Look back at past heartbeats | `cmdHistory` → `readHistory` in `src/heartbeat.ts:206` |
| `sandbox` | List sandboxes or clean up stopped ones | `cmdSandbox` in `src/index.ts:184` |
| `run` | Try one task right now, without waiting for the server | `cmdRun` → `executeTask` in `src/execution.ts:309` |
| `version` / `help` | Check the version or get help | `main()` in `src/index.ts:267` |

Quick copy-paste reference (`helpText()`, `src/cli.ts:186`):

```text
uma-machine enroll --server <url> [--name <machine>] [--systemd] [--client-id <id>]
uma-machine daemon [--interval <seconds>]
uma-machine check [--only <k1,k2>] [--json]
uma-machine reset [--only <k1,k2>] [--dry-run] [--prune]
uma-machine reset --fresh-start --sandbox <id> [--commit <sha>] [--repo <url>] [--branch <b>] [--task <id>] [--dry-run]
uma-machine sync [--dry-run] [--json] [--only <k1,k2>]
uma-machine history [--range 24h|30d] [--json]
uma-machine sandbox list [--json]
uma-machine sandbox prune [--dry-run]
uma-machine run --task <id> [--prompt <text>] [--project <id>] [--repo <url>] [--commit <sha>] [--branch <b>] [--agent <bin>]
uma-machine version
```

## Global flags

| Flag | What it does |
| --- | --- |
| `-h, --help` / `help [command]` | Show overall help, or help for one command (`src/index.ts:274`) |
| `-v, --version` / `version` | Show `uma-machine ${CLI_VERSION} (protocol v1)` (`src/version.ts:1`, `CLI_VERSION = "0.1.0"`) |

Tip: numbers that look numeric stay strings (`parseCli`, `src/cli.ts:146`), and repeating `--only a --only b` joins to `"a,b"`.

## Config keys (`--only`)

Checked in dependency order (`ORDERED_KEYS`, `src/config/mod.ts:22`):

`programs, git-login, adityab-agent, agents, files, providers, mcp, skills, systemd`

Heads-up: `sync` is just another name for `skills` (`resolveKeys`, `src/config/mod.ts:34`). Unknown keys are politely rejected by `parseOnlyFlag` (`src/env.ts:101`).

## Exit codes at a glance

| Code | What it means |
| --- | --- |
| `0` | All good |
| `2` | Something drifted (`check`) or partly converged (`reset`, `sync`) |
| `1` | Something went wrong (unknown command, missing flag, `run` didn't complete, fresh-start failed) |
| `3` | Daemon only: server says `UPGRADE_REQUIRED` (`src/daemon.ts:56`) |

Tables respect `NO_COLOR` and non-TTY output: `humanTable()` in `src/index.ts:25` drops styling, and errors are secret-redacted and trimmed to 300 chars (`safeError`, `src/index.ts:47`).

## Environment variables

| Variable | Default | Used for |
| --- | --- | --- |
| `UMA_SERVER_URL` / `UMA_SERVER` | `http://127.0.0.1:3000` | Default `--server` for `enroll` (`serverUrl()`) |
| `UMA_MACHINE_ROOT` / `UMA_CONFIG_HOME` / `UMA_DATA_HOME` / `XDG_*` | platform dirs | Where identity, limits, and `state.db` live |
| `UMA_STATE_DB` | under machine root | `history`, receipts, heartbeat rows |
| `UMA_HEARTBEAT_INTERVAL_S` | `30` (min 5) | Default daemon tick |
| `UMA_HEARTBEAT_RETENTION_DAYS` | `30` | How long `history` keeps rows |
| `UMA_SANDBOX_TTL_S` | `3600` (min 60) | When stopped sandboxes get reaped |
| `UMA_AGENT_BIN` | auto-detected agent | Default for `run --agent` |
| `UMA_EXEC_PATH` | binary path | systemd `ExecStart` |
| `GH_TOKEN` / `GITHUB_TOKEN` | — | Redacted from logs, used for git auth |
| `MSB_MOCK` / `UMA_MSB_MOCK=1` | unset | Force the mock sandbox driver in tests |
