```text
uma-machine sandbox [list|prune] [--json] [--dry-run]
```

## `sandbox list`

`listSandboxes()` table: `id | task | project | status` (`created` cyan, `running` green, `stopped` yellow, `destroyed` red). `--json` prints the raw array. Always exits `0`.

```bash
uma-machine sandbox
uma-machine sandbox list
uma-machine sandbox list --json
```

## `sandbox prune`

Removes every sandbox with `status == stopped` (`removeSandbox`). `--dry-run` prints `would prune <id>` without removing. Prints `<n> stopped sandbox(es)` at the end. Running sandboxes are never touched. Always exits `0`.

```bash
uma-machine sandbox prune --dry-run
uma-machine sandbox prune
```

Unknown subcommands (`uma-machine sandbox foo`) print `unknown sandbox subcommand: foo` and exit `1`.

Underlying driver invocations (`src/sandbox/cli.ts:29`): `create <UBUNTU_IMAGE> -n <name> … --label task.id= --label project.id=`, `start`, `stop [--force]`, `remove --force`, `list --format json`, `exec <name> -- <cmd>…`. Driver selection is `sdk → cli → fail-closed` (`src/sandbox/driver.ts`); tests force the mock with `MSB_MOCK=1`.
