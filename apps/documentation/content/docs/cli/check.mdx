Wondering if your machine still matches its desired setup? `check` takes a safe look and tells you. Defined in `apps/machine/src/cli.ts:50`, handled by `cmdCheck` in `apps/machine/src/index.ts:66`.

```text
uma-machine check [--only <k1,k2>] [--json]
```

## Flags

| Flag | When to use it |
| --- | --- |
| `--only <k1,k2>` | Just check these config keys (see [/cli](/cli)). Parsed by `parseOnlyFlag`. |
| `--json` | Get the raw `checkAll()` result array as JSON instead of the friendly table. |

We run `checkAll(only)` over `ORDERED_KEYS` (`src/config/mod.ts:43`). The human-friendly output is a table with `key | status (ok / DRIFTED) | detail`.

## What the exits mean

| Code | What it means |
| --- | --- |
| `0` | Everything you checked looks clean — nice! |
| `2` | At least one key drifted — see `reset` to fix it |

## Try it

```bash
uma-machine check
uma-machine check --only programs,systemd
uma-machine check --json
```
