## Behavior

- **Tick:** `setInterval(..., intervalS * 1000)` (`src/daemon.ts:165`), plus one immediate heartbeat on connect (`onOpen`) and one at startup. `intervalS` comes from `daemonIntervalS()` (floor 2s, default 30s).
- **Persist-first:** `persistHeartbeat(frame)` writes SQLite before `send(frame)` — a send failure never loses the row, and `uma-machine history` stays queryable offline.
- **Pressure hint:** `evaluateScopeHint()` sets `scopeHint` when host pressure exceeds `PRESSURE_THRESHOLD_PCT` (90%) with `PRESSURE_ATTRIBUTION_PCT` (60%) attribution sustained `PRESSURE_SUSTAINED_S` (600s), with a `PRESSURE_COOLDOWN_S` (600s) cooldown. Constants in `apps/orpc-contract/src/constants.ts:13`.
- **Retention:** `UMA_HEARTBEAT_RETENTION_DAYS` (default 30).
