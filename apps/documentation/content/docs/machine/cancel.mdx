## Behavior

- Marks the in-flight task cancelled via the in-flight map.
- Runs `stopSandbox --force` for the task's sandbox (falls back to label lookup `task.id` when the map has no entry).
- Best-effort and idempotent: cancelling an unknown or already-finished `taskId` is a no-op, never an error frame.
- No ack frame exists for `cancel` in `v1` — completion surfaces as the subsequent `task-done { status: "failed" }` or the sandbox going `stopped`.
