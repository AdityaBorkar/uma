## Behavior

- If `CLI_VERSION >= minVersion` → `UPGRADE_REQUIRED ignored` warning, daemon keeps running.
- If `CLI_VERSION < minVersion` → `UPGRADE_REQUIRED: daemon <cli> < min <min> (<reason ?? "major mismatch">). Re-run install.sh.` and `process.exit(3)`.

Exit `3` is reserved for this case across the CLI (see [/cli](/cli)). Wire-frame changes require a major version and go through this path — see [/contracts/versioning](/contracts/versioning).
