---
title: Execution pipeline
description: assign → quota → claim → start → bind → exec → task-done → stop.
---

Implemented in `apps/machine/src/execution.ts:309` (`executeTask`), shared by daemon `assign` handling and `uma-machine run`. Diagram: [/visualize/machine](/visualize/machine).

```mermaid
flowchart TD
    A["assign"] --> B["quotaPreCheck"]
    B -->|over| C["quota-exceeded plus claim-ack false to refused"]
    B -->|ok| D["create sandbox"]
    D --> E["POST claim"]
    E -->|conflict or error| F["claim-ack false to rejected"]
    E -->|claimed| G["claim-ack true to start"]
    G --> H["ensureBinding"]
    H --> I["execStream redacted to log frames"]
    I --> J["task-done to stop"]
```
