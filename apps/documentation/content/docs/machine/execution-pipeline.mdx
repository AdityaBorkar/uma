---
title: Execution pipeline
description: assign → quota → claim → start → bind → exec → task-done → stop.
---

Implemented in `apps/machine/src/execution.ts:309` (`executeTask`), shared by daemon `assign` handling and `uma-machine run`. Diagram: [/visualize/machine](/visualize/machine).

```text
assign ─▶ quotaPreCheck ─(over)─▶ [quota-exceeded + claim-ack ok:false] ─▶ refused
   │─(ok)─▶ create sandbox ─▶ POST /rpc/tasks.claim ─(409/4xx)─▶ [claim-ack ok:false] ─▶ rejected, free sandbox
   │─(claimed)─▶ [claim-ack ok:true] ─▶ start ─▶ ensureBinding (clone/fetch/checkout task/<short>, optional freshStart)
   │─▶ execStream (redacted, ≤256KB chunks → log frames) ─▶ task-done {completed|failed} ─▶ stop (stopped, for TTL reap)
```
