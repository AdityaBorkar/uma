Welcome! UMA connects your machines, your tasks, and your web app so work flows smoothly from idea to done.

Think of it in four friendly pieces:

- **Product web app** (`apps/web`) — where you triage signals, create tasks, and watch progress. Built with TanStack Start, oRPC, and Drizzle/PostgreSQL.
- **Device agent** (`apps/machine`) — the `uma-machine` CLI and daemon that runs tasks safely inside microsandbox sandboxes and stays in touch over HTTPS + WebSocket.
- **Wire contract** (`apps/orpc-contract`) — the frozen `v1` language machines and servers share, so upgrades never surprise you.
- **Infra** (`apps/infra`) — the Pulumi program that provisions OCI, Cloudflare, and Docker.

## How these docs stay honest

Every page names the source file it describes. Ground truth lives here:

- CLI surface: `apps/machine/src/cli.ts`, `apps/machine/src/index.ts`
- Daemon: `apps/machine/src/daemon.ts`, `execution.ts`, `heartbeat.ts`, `ws-client.ts`, `enroll.ts`
- Wire frames: `apps/orpc-contract/src/schemas/machine-frames.ts`, `server-frames.ts`, `constants.ts`, `ids.ts`, `contracts/ws.ts`, `contracts/api.ts`, `schemas/`
- Web router + machine server: `apps/web/src/rpc/router.ts`, `apps/web/src/rpc/procedures/*`, `apps/web/src/routes/api/rpc.$.ts`, `apps/web/server/machines-ws.ts`, `apps/web/src/lib/machines/`
