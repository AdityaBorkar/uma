UMA is a Bun monorepo with four runtime pieces:

- **Product web app** (`apps/web`) — TanStack Start + oRPC + Drizzle/PostgreSQL. Owns projects, signals, tasks, documents, connections.
- **Device agent** (`apps/machine`) — `uma-machine` CLI + daemon. Runs tasks in microsandbox sandboxes, talks to the server over HTTPS + WebSocket.
- **Wire contract** (`apps/orpc-contract`) — frozen `v1` machine↔server frames plus the contract-first API/WS routers.
- **Infra** (`apps/infra`) — Pulumi program (OCI + Cloudflare + Docker).

## Interactive visualizations

The `visualize/*` routes render the same material as Mermaid diagrams (rendered client-side in the new docs fonts):

- `/visualize` — hub with links to all five diagrams
- `/visualize/cli` — CLI command tree
- `/visualize/machine` — daemon dispatch + heartbeat loop
- `/visualize/contract-machine-server` — WS frames, both directions
- `/visualize/contract-server-web` — oRPC router (server ↔ web frontend)
- `/visualize/architecture` — end-to-end connection and architecture
