<h1 class="mt-1 text-3xl font-semibold">How your browser talks to the server</h1>

<p class="mt-2 max-w-2xl text-fd-muted-foreground">Your TanStack frontend calls <code class="font-mono">POST /api/rpc/*</code> (<code class="font-mono">RPCHandler</code>), which reads and writes Postgres via Drizzle. Auth via <code class="font-mono">requireUser</code>; pages come back as <code class="font-mono">{"{items, nextCursor}"}</code>. Full detail: <a class="text-fd-primary hover:underline" href="/contracts/server-web">/contracts/server-web</a>.</p>
