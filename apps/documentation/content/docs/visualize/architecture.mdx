<h1 class="mt-1 text-3xl font-semibold">How everything connects</h1>

<p class="mt-2 max-w-2xl text-fd-muted-foreground">Follow a task from your terminal to its sandbox to your browser. Want words instead of pictures? See <a class="text-fd-primary hover:underline" href="/architecture">/architecture</a>.</p>

<Mermaid chart={chart} ascii={ascii} />

<div class="mt-6 grid gap-4 md:grid-cols-2">
  <div class="rounded-xl border border-fd-border bg-fd-card p-5">
    <h2 class="font-semibold">1 · Enroll</h2>
    <p class="mt-1 text-sm text-fd-muted-foreground"><code class="font-mono">uma-machine enroll</code> → approve in the browser → <code class="font-mono">identity.json (0600)</code>, <code class="font-mono">limits.json</code>, <code class="font-mono">state.db</code>, optional systemd unit.</p>
  </div>
  <div class="rounded-xl border border-fd-border bg-fd-card p-5">
    <h2 class="font-semibold">2 · Stay in touch</h2>
    <p class="mt-1 text-sm text-fd-muted-foreground">Bearer WebSocket + persist-first heartbeat (30s) + tidy-up of stopped sandboxes. Handles assign / cancel / reset-config / UPGRADE_REQUIRED.</p>
  </div>
  <div class="rounded-xl border border-fd-border bg-fd-card p-5">
    <h2 class="font-semibold">3 · Run work</h2>
    <p class="mt-1 text-sm text-fd-muted-foreground">Reserve a sandbox → atomic claim (409 means someone else won) → start → git bind (<code class="font-mono">task/&lt;short&gt;</code>) → redacted run → <code class="font-mono">task-done</code> → stop.</p>
  </div>
  <div class="rounded-xl border border-fd-border bg-fd-card p-5">
    <h2 class="font-semibold">4 · Watch in the browser</h2>
    <p class="mt-1 text-sm text-fd-muted-foreground">Signal → Task (queued) → assign → running → completed/failed. The frontend calls <code class="font-mono">tasks.list/stats</code> over <code class="font-mono">POST /api/rpc/*</code>.</p>
  </div>
</div>
